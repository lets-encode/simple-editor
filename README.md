# simple-editor

This repository will eventually house a simple graphical editor for the
[Let's Encode!](https://lets-encode.mdw.ac.at/) project: a way to view and correct music
encodings (MEI) directly on the rendered score, without ever having to read or write XML.
It is at an early stage. For now it holds only a throwaway prototype in [`spike/`](spike/)
for trying out touch gestures, not the editor itself.
